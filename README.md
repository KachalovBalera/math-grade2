# Приложение «Считайка — Математика, 2 класс»

Полноценное мобильное интерактивное обучающее приложение для Android-смартфонов и планшетов (а также веб-браузеров) для обучения математике по программе 2-го класса начальной школы («Школа России», учебник М.И. Моро).

Приложение разработано в формате развивающей игры, чтобы ребёнок 7–9 лет мог самостоятельно осваивать программу, решать примеры, уравнения и задачи, получать наглядные пошаговые объяснения ошибок, зарабатывать награды и отслеживать личный прогресс.

## 🌟 Ключевые возможности и особенности

1. **Дружелюбный детский интерфейс (7–9 лет):**
   - Все надписи, задания и пояснения на русском языке.
   - Крупные контрастные кнопки для пальцев и крупный читаемый шрифт.
   - Поддержка вертикальной и горизонтальной ориентации на телефонах и планшетах.
   - Полный офлайн — без рекламы, без покупок и без обязательной регистрации.
   - **Встроенная система обновлений (как в приложении «Русский язык»):** автоматическая проверка новой версии при запуске, скачивание APK с индикатором прогресса и запуск нативного установщика Android!

2. **Главный экран и навигация:**
   - «Начать заниматься» / «Продолжить обучение» (автоматический возврат к последней теме).
   - «Тренировка дня» (адаптивный ежедневный микс из 10 заданий с учётом ошибок).
   - «Выбрать тему» (каталог из 12 тем школьной программы).
   - «Переход через десяток» (специализированный тренажёр для каждого круглого десятка).
   - «Примеры со скобками» (интерактивный двухэтапный тренажёр с записью над скобками).
   - «Устный счёт» и «Решаем задачи».
   - «Мои ошибки» (персональный банк ошибок с пошаговыми решениями и режимом исправления).
   - «Мои достижения» (значки за все десятки от 20 до 90, скобки, задачи, серии дней).
   - Индикаторы: общий прогресс (в %), заработанные золотые звёзды, серия дней занятий (streak).
   - Раздел «Для родителей» (защищён математическим замком): статистика точности, освоение тем и рекомендации.

3. **Специальный тренажёр «Переход через десяток» (Раздел 4):**
   - **8 независимых кнопок переходов:** через 20, 30, 40, 50, 60, 70, 80, 90 + режим «Все десятки».
   - **6 режимов тренировки:**
     1. Сложение с переходом через десяток.
     2. Вычитание с переходом через десяток.
     3. Сложение и вычитание вперемешку.
     4. Примеры с пропущенными числами (`38 + □ = 43`, `43 − □ = 36`).
     5. Смешанная тренировка (примеры + текстовые задачи на переход).
     6. Контрольная работа (проверка без подсказок).
   - **3 уровня сложности:**
     - *Уровень 1 («С подсказкой»):* интерактивная числовая прямая и схема разложения слагаемого/вычитаемого до круглого десятка и остатка.
     - *Уровень 2 («Решаю сам»):* пример + кнопка открытия подсказки при затруднении.
     - *Уровень 3 («Без подсказок»):* самостоятельное решение без подсказок.
   - Выбор количества примеров: 5, 10, 15 или 20.
   - Индивидуальная статистика освоения по каждому десятку.

4. **Специальный тренажёр «Примеры со скобками» (Раздел 5):**
   - **Главная механика:** двухэтапный ввод с визуальным полем **НАД скобками**.
   - *Шаг 1:* ребёнок видит пример `18 − (16 − 7) = ?`. Вводит промежуточный ответ `9` в поле, расположенное ровно над выражением в скобках.
   - *Шаг 2:* после проверки показывается преобразованное выражение `18 − 9 = ?` (скобки заменяются числом `9`). Ребёнок вводит итоговый ответ.
   - Показ полного пошагового решения:
     1-е действие: `16 − 7 = 9`
     2-е действие: `18 − 9 = 9`
     Итог: `9`.

5. **Все остальные темы программы 2 класса:**
   - **Раздел A. Числа и нумерация:** чтение, запись до 100, десятки и единицы, разрядный состав, сравнение `<, >, =`, предыдущее/следующее, числовой ряд.
   - **Раздел B. Состав числа:** «Домики состава числа», пары слагаемых, разложение на десятки и единицы.
   - **Раздел C. Сложение и вычитание:** круглые десятки, двузначные без перехода и с переходом через разряд (`38 + 24 = 62`), наглядное разложение по разрядам.
   - **Таблица умножения и деления:** смысл действия как суммы одинаковых слагаемых, таблица на 2, 3, 4, 5, нахождение неизвестного множителя и делимого/делителя.
   - **Порядок действий:** выражения в 2–3 действия со скобками и без, сравнение выражений.
   - **Уравнения:** нахождение неизвестного слагаемого, уменьшаемого, вычитаемого (`x + 7 = 15`, `18 − x = 10`), проверка подстановкой.
   - **Текстовые задачи:** интерактивный разбор краткой записи («Было — Изменилось — Стало»), нахождение суммы, остатка, разностное сравнение («на сколько больше/меньше»), задачи в 2 действия.
   - **Геометрия:** вершины и стороны многоугольников, свойства квадрата и прямоугольника, нахождение периметра `P = a + b + c + d`.
   - **Величины и время:** сантиметры, дециметры, метры, килограммы, литры; интерактивные часы со стрелками; счёт рублей и копеек, задачи на покупки и сдачу.
   - **Логика и головоломки:** закономерности, загадки двух чисел («Сумма 20, разность 4»), поиск лишнего числа, магические тройки.

6. **Банк заданий и математическая верификация:**
   - 240+ проверенных статических вопросов (не менее 20 на каждую тему) с готовыми объяснениями и подсказками.
   - Динамические математические генераторы с гарантированным попаданием в заданные разряды.
   - 100% покрытие автоматическими тестами: проверено 1 605 математических утверждений.

## 🚀 Запуск и тестирование

### 1. Запуск в веб-браузере (для моментального тестирования):
```bash
npm run web
```
Приложение откроется в браузере с адаптивным макетом для смартфонов и планшетов.

### 2. Запуск на Android через Expo Go:
```bash
npm start
```
Отсканируйте появившийся QR-код камерой смартфона в приложении Expo Go на Android.

### 3. Запуск автоматических тестов:
```bash
npx tsx tests/verifyMath.ts
```
Тест проверяет корректность генерации всех 8 переходов через десятки (20..90), двухэтапных скобок, уравнений, геометрии и банка вопросов.

## 📦 Сборка Android APK

Проект полностью настроен и подготовлен к сборке APK двумя способами:

### Вариант A. Сборка через EAS Build (облачная сборка Expo):
1. Установите EAS CLI: `npm i -g eas-cli`
2. Авторизуйтесь: `npx eas-cli login`
3. Запустите сборку готового автономного APK:
   ```bash
   npx eas-cli build --platform android --profile preview
   ```
По завершении сборки вы получите прямую ссылку на скачивание установочного `.apk` файла для установки на смартфон или планшет.

### Вариант B. Локальная сборка через Gradle:
1. Установите JDK 17 или новее и Android SDK (Android Studio).
2. Задайте переменную окружения `JAVA_HOME`.
3. В папке проекта выполните:
   ```bash
   cd android
   ./gradlew assembleRelease
   ```
Собранный файл будет находиться по пути:
`android/app/build/outputs/apk/release/app-release.apk`.
